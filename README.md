# 🏭 Big Ambitions Tools

A fan-made companion app for the game _Big Ambitions_, designed to help players plan, optimize, and manage their factory setups and logistics.

**Live Site:** <https://big-ambitions-tools.com>

---

## ✨ Features

- 🏗 **Factory Planner**
  Calculate production stats, required ingredients, and optimal worker counts

- 🔗 **Factory Grouping**
  Combine multiple factories to manage complex logistics and dependencies

- 📊 **Overview Dashboard**
  Track weekly order costs, employee salaries, and production metrics at a glance

- 📦 **Shopping List Generator**
  Automatically calculate required imports based on your setup

- 🚚 **Delivery Plans**  
  Shows how many items to deliver from warehouses to factories – copy & paste ready

- 🗃 **Game Database**
  Browse detailed information about products, machines, vehicles, and more

- 🌍 **Multi-language Support**
  Fully localized UI across multiple languages

---

## 🛠 Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **State Management:** Zustand
- **Forms:** React Hook Form
- **Styling:** Tailwind CSS

---

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/Dudeldups/big-ambitions-tools.git
cd big-ambitions-tools
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

---

## 🐳 Docker

```bash
docker-compose up -d
```
